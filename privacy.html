Privacy policy

Home Assistant Nest is a personal integration used only by its owner.

  • It accesses Google Nest device data (thermostat status, temperature, humidity, settings) solely to display and control that device in the owner's own Home Assistant server.
  • Data is stored only on that server, inside the owner's home. It is not sold, shared with, or transferred to any third party, and is not used for advertising.
  • Access can be revoked at any time from the Google account's third-party access settings; removing the integration deletes the data on the home server.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue on this site's GitHub repository.
